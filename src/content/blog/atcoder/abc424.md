## A 题：签到

题意：读入一个整数并原样输出。注意用 `long long` 防止溢出：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  long long n;
  cin >> n;
  cout << n << '\n';
  return 0;
}
```

```cpp

for (int i = 0; i < n; i++) pref[i + 1] = pref[i] + a[i];

// 查询 [l, r]
```
